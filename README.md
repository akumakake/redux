3.	Services App — управление услугами с поиском
CRUD-приложение на React для управления списком услуг: добавление, редактирование, удаление и фильтрация по названию. Состояние хранится в Redux, фильтрация вынесена в мемоизированные селекторы.
Возможности
•	Добавление, редактирование и удаление услуг
•	Валидация полей формы и показ ошибок
•	Поиск по названию в реальном времени
•	Статистика: «Найдено: X из Y услуг»
Технологии
•	React (TypeScript) — библиотека для построения UI
•	Vite — сборка и dev-сервер
•	Redux Toolkit — управление состоянием приложения
•	CSS — стилизация и адаптивная вёрстка
